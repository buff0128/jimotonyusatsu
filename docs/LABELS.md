# 参加しやすさのラベル

案件ページの上部と一覧の各行に出す「紙で入札できる」などのラベルの定義。
ルールの正本は [src/lib/labels.ts](../src/lib/labels.ts)（サイトと同期スクリプトが同じ関数を使う）。サイト上の説明は `/guide/labels`（labels.ts から生成）。

## 考え方

- **AI にラベルを判定させない。** AI は公告から「事実の項目」（入札方法、保証金、地域要件、資格と等級、実績要件、予定価格）を抽出するだけ。ラベルはその値に決まったルールを当てはめて付ける
- ラベルは公告を AI で読んだ案件にだけ付く。付いていないことは「当てはまらない」ではなく「判定していない」場合がある
- 抽出値が `null`（読み取れなかった）のときは、ラベルを付けない側に倒す

## 一覧

| # | ラベル | slug | 付ける条件 |
|---|---|---|---|
| 1 | 紙で入札できる | `paper` | 入札方法が「紙のみ」または「電子・紙どちらも可」 |
| 2 | 保証金が免除 | `no-bond` | 入札保証金と契約保証金がどちらも「免除」 |
| 3 | 地元業者向け | `local` | 地域要件が「市区町村内」または「都道府県内」に本店・営業所などがあること |
| 4 | 全省庁統一資格C以下で参加可 | `zensho-c` | 必要な資格に全省庁統一資格があり、参加できる等級にCまたはDが含まれる |
| 5 | 少額 | `small` | 予定価格が公表されていて、300万円以下 |
| 6 | 実績要件なし | `no-experience` | 同種・類似業務の実績が参加条件になっていない |

## 使っている抽出項目（scripts/lib/case-ai.mjs）

| 項目 | 値 |
|---|---|
| `bid_method` | `electronic`（電子のみ。障害時だけ紙を認めるものを含む）／`both`（申請・承認で紙も一般に可）／`paper` |
| `bid_bond` | `exempt`／`required`（条件付き免除でも原則が納付なら required） |
| `contract_bond` | `exempt`／`required`／`partial`（一部免除・保険や保証証券で代えられる） |
| `local_requirement` | `city`（市区町村内）／`prefecture`（都道府県内。県内の一部地域を含む）／`region`（複数の都道府県にまたがる地域）／`none` |
| `licenses[].kind` / `grades` | `zensho`（全省庁統一資格）などと、参加できる等級の配列 |
| `experience_required` | 実績が参加条件なら true |
| `estimated_price` | 予定価格（円）。公表されているときだけ。提案上限額・予算額などは入れない |

## 変えるとき

1. `src/lib/labels.ts` の `LABELS` を直す（slug を変えると `?label=` の URL が変わる）
2. この文書の一覧を更新する
3. `pnpm sync:d1`（差分。ラベルが変わった案件の `case_labels` だけが送られる）
