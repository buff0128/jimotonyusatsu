# 出典・免責事項

## 出典

本サイトの入札案件情報は、中小企業庁が運営する[官公需情報ポータルサイト](https://www.kkj.go.jp/s/)の検索APIを利用して取得しています。

官公需情報ポータルサイトへの掲載は、発注機関がホームページで公開してから1日程度遅れることがあります。また、発注機関が公告するすべての案件を網羅するものではありません。

## AIによる情報の生成について

本サイトでは、案件の理解を助けるため、公告文や公告資料をもとに次の情報をAIで作成している場合があります。

- 業務内容の要約
- 公告文から読み取った日程、参加資格、入札方法、業種などの項目

AIで作成した情報には、その旨をページ内に表示しています。AIによる情報には誤りが含まれる可能性があります。件名、発注機関、公告日など、取得元から提供されたままの情報とは区別して掲載しています。

## 免責事項

- 掲載情報の正確性・完全性には注意を払っていますが、内容を保証するものではありません。
- 入札への参加を検討する際は、必ず発注機関が公表する公告・入札説明書・仕様書などの原本で、日程や参加資格を確認してください。
- 本サイトの情報を利用したことにより生じた損害について、運営者は責任を負いません。
- 本サイトは発注機関とは関係がなく、入札手続きの代行や、個別の案件についてのお問い合わせへの回答は行っていません。案件の内容については、各発注機関へお問い合わせください。
- 掲載内容は、予告なく変更・削除することがあります。
