# 運営者情報

## サイトについて

じもと入札は、国や自治体などが公告する入札案件を、登録なし・無料で探せる入札情報サイトです。

入札の情報は、発注機関ごとにさまざまなサイトやシステムに分かれて掲載されています。地元の中小企業や個人事業主の方が、自社に合う案件を手軽に見つけられるよう、案件を1件ずつ整理して掲載しています。
