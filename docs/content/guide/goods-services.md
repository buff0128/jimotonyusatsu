# 物品・役務の入札のコツ

官公庁の入札は、工事だけではありません。庁舎の清掃、施設の警備、広報誌の印刷、システムの開発や保守、事務用品やパソコンの納入など、「物品」と「役務（サービス）」の仕事が数多く発注されています。

物品・役務の入札は、建設工事に比べて参加の準備が少なく、中小企業や個人事業主でも参加しやすいのが特徴です。一方で、業種ごとに仕様書で見るべき点や、必要な許認可が違います。このページでは、代表的な業種ごとに、参加を検討するときの見どころをまとめました。

## まず共通して確認すること

どの業種でも、公告と仕様書で次の点を最初に確認します。

- **参加資格の区分と等級**：「役務の提供等」「物品の販売」など、自社が登録している区分と等級で参加できるか
- **地域の条件**：発注機関の地域内に本店や営業所があることを条件にしていないか
- **契約の期間**：1回きりの納品か、1年間の業務か、複数年の契約か
- **金額の決まり方**：総額で決まるのか、単価（1回あたり、1部あたりなど）で決まるのか
- **現地説明会**：参加が条件になっている説明会がないか。欠席すると参加できない場合があります

公告の基本的な読み方は[入札公告の読み方と用語集](/guide/reading-notices)で解説しています。

## 清掃

庁舎、学校、公園のトイレなどの日常清掃や、床のワックスがけ、窓ガラスの清掃などです。

- **仕様書で見るところ**：清掃する面積、回数（毎日・週1回・月1回など）、作業できる時間帯、使う資材を誰が用意するか
- **人件費の見積もり**：清掃は人件費が費用の大部分を占めます。作業時間と人数から、最低賃金を下回らない人件費を見積もることが大切です
- **許認可・資格**：建物の規模や業務の内容によっては、建築物清掃業などの都道府県の登録を求められることがあります

関連する案件は[清掃の案件一覧](/gyoshu/seiso)から探せます。

## 警備

施設の常駐警備、巡回警備、イベントの交通誘導などです。

- **許認可**：警備業を営むには、都道府県公安委員会の認定が必要です。認定のない事業者は参加できません
- **仕様書で見るところ**：配置する人数と時間、24時間体制かどうか、機械警備との組み合わせ、必要な検定資格（施設警備、交通誘導警備など）
- **人員の確保**：夜間や休日の配置が多い業務では、契約期間を通して人員を確保できるかが重要です

関連する案件は[警備の案件一覧](/gyoshu/keibi)から探せます。

## 印刷・製本

広報誌、パンフレット、ポスター、報告書、封筒などの印刷です。地元の印刷会社が参加しやすい分野です。

- **仕様書で見るところ**：部数、ページ数、判型、用紙の種類、色数、製本の方法、校正の回数、納品の場所と分納の有無
- **データの作成を含むか**：原稿からデザインやレイアウトを作るのか、完成したデータを印刷するだけなのかで、手間と金額が大きく変わります
- **単価契約**：封筒や名刺などは、1年間の単価で契約し、注文のたびに納める形がよくあります

関連する案件は[印刷・製本の案件一覧](/gyoshu/insatsu)から探せます。

## システム開発・運用

業務システムの開発や改修、ホームページの制作や更新、システムの保守・運用などです。

- **方式**：価格だけで決める入札のほか、企画提案を評価するプロポーザル方式や、価格と技術を合わせて評価する総合評価方式がよく使われます（[入札方式の違い](/guide/bidding-methods)）
- **仕様書で見るところ**：開発の範囲、納期、既存システムとの連携、運用・保守の期間、データの移行、セキュリティの要件
- **求められることがある条件**：情報セキュリティの認証（ISMSなど）や、個人情報保護の体制（プライバシーマークなど）、同じ規模の開発の実績
- **費用の見積もり**：要件が曖昧なまま安く見積もると、受注後に作業が膨らみます。不明な点は質問の期間中に必ず確認しましょう

関連する案件は[システム開発・運用の案件一覧](/gyoshu/system)から探せます。

## 物品の納入

事務用品、パソコン、家具、車両、防災用品などの購入です。

- **仕様書で見るところ**：品名、型番、数量、納入の期限と場所、設置や配線の作業を含むか、古い物品の引き取りの有無
- **「同等品可」かどうか**：型番が指定されていても、同じ性能の別の製品で納められる場合があります。同等品で納めるときは、事前に承認を受ける手続きが必要なことがあります
- **仕入れの確認**：入札の前に、メーカーや卸から納期と仕入れ値を確認しておきます。落札しても期限までに納められなければ契約違反になります

関連する案件は[パソコン・IT機器](/gyoshu/it-kiki)や[事務用品・家具](/gyoshu/jimu)の一覧から探せます。

## 設備の保守・点検

エレベーター、空調、消防設備、自家発電設備などの定期点検です。

- **資格**：点検の内容によって、法令で決められた資格者が必要です（消防設備点検の資格など）
- **メーカーとの関係**：特定のメーカーの設備は、そのメーカー系列でないと対応が難しい場合があります。仕様書で、対象の設備のメーカーと型式を確認しましょう

関連する案件は[設備の保守・点検の案件一覧](/gyoshu/hoshu-tenken)から探せます。

## 見積もりで気をつけること

- **税抜きの金額で入札する**：多くの入札では、消費税を含まない金額を書くルールです
- **複数年の契約は総額を確認する**：1年あたりの金額で入札するのか、契約期間全体の総額で入札するのかを確認します
- **安すぎる金額に注意する**：最低制限価格を下回ると失格になる案件があります。また、無理な金額で受注すると、人員や品質を確保できなくなります
- **前回の結果を参考にする**：同じ業務は毎年発注されることが多く、前年度の落札金額が公表されていれば、相場の目安になります（[落札結果と落札率の見方](/guide/award-results)）

## まとめ

物品・役務の入札は、業種によって見るべきところが違います。仕様書の数量、回数、期間を自社の体制に当てはめて、無理なく履行できるかを判断することが、落札後に困らないための一番のコツです。

[じもと入札](/)では、[業種から探す](/gyoshu)ページで、清掃、警備、印刷、システム開発など業種ごとに案件を探せます。
