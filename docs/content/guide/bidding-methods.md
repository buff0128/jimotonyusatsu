# 入札方式の違い

国や自治体が契約の相手を決める方法は、ひとつではありません。方式によって、参加できる事業者や、評価される点が変わります。

## 1. 一般競争入札

条件を満たす事業者であれば、誰でも参加できる方式です。国や自治体の契約では、これが原則とされています。

- 公告を見て、参加資格を満たしていれば申し込めます
- 原則として、予定価格の範囲内で最も安い金額を出した事業者が落札します
- 「本店が県内にあること」など、地域や実績の条件が付く「条件付き一般競争入札」も多く行われています

**初めての方にとって、最も参加しやすい方式です。**

## 2. 指名競争入札

発注機関があらかじめ指名した事業者だけが参加できる方式です。指名されるには、資格を持っていることに加え、実績や地域などが考慮されるのが一般的です。

初めての事業者がいきなり指名されることは少ないため、まずは一般競争入札で実績を積むことが近道になります。

## 3. 随意契約

入札をせずに、発注機関が相手を選んで契約する方式です。法令で認められた場合に限って行われます。

- **少額随意契約**：金額が一定以下の契約。複数の事業者から見積もりを取って決めることが多いです
- **特命随意契約**：特定の事業者にしか対応できない場合など

### オープンカウンター方式

少額の案件で、見積もりの参加者を広く募る方式です。発注機関のホームページなどで案件を公開し、見積書を出した事業者の中から、最も安い事業者に決めます。手続きが比較的簡単なので、**入札に慣れていない事業者の最初の一歩に向いています。**

## 4. 総合評価方式

価格だけでなく、技術力、品質、実績、提案内容なども点数化し、価格と合わせて総合的に評価して落札者を決める方式です。工事や、品質が重視される業務で使われます。

価格が最も安くなくても、提案内容が評価されれば落札できる可能性があります。

## 5. プロポーザル方式（企画競争）

価格よりも、企画や提案の内容で相手を選ぶ方式です。計画づくり、調査、イベント運営、システムの企画など、内容の良し悪しが結果を大きく左右する業務で使われます。

- 企画提案書を提出し、プレゼンテーションや審査を経て選ばれます
- 選ばれた事業者と随意契約を結ぶ形が一般的です
- 準備の手間はかかりますが、得意分野がはっきりしている事業者には大きなチャンスです

## どの方式から始めるべきか

| 状況 | おすすめの方式 |
|---|---|
| 入札が初めて | オープンカウンター、少額の一般競争入札 |
| 価格競争力がある | 一般競争入札 |
| 技術や企画に強みがある | 総合評価方式、プロポーザル方式 |
| 地域での実績を積みたい | 地元の自治体の条件付き一般競争入札 |

どの方式で行われるかは、公告に書かれています。案件を探すときは、方式もあわせて確認してみてください。用語の意味は[入札公告の読み方と用語集](/guide/reading-notices)をご覧ください。
