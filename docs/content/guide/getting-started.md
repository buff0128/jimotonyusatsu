# 入札の始め方

国や自治体は、庁舎の清掃、広報誌の印刷、パソコンの購入、道路の補修工事など、毎日たくさんの仕事を民間の事業者に発注しています。その多くは「入札」で相手を決めており、条件を満たせば中小企業や個人事業主でも参加できます。

このページでは、初めて入札に参加するまでの流れを順番に説明します。

## 入札のメリット

- **景気に左右されにくい**：予算に基づいて毎年発注されるため、民間の仕事が減る時期でも案件があります。
- **支払いが確実**：発注者が国や自治体なので、代金の未払いの心配がほとんどありません。
- **営業のしかたが明確**：公告を見て条件に合えば応募できるので、人脈や紹介がなくても参加できます。
- **実績になる**：官公庁との取引実績は、民間の取引先からの信用にもつながります。

## 全体の流れ

### 1. 入札参加資格を取る

入札に参加するには、多くの場合、発注機関ごとの「入札参加資格」を事前に取っておく必要があります。

- **国の機関の物品・役務**：全省庁共通の「全省庁統一資格」
- **自治体**：都道府県や市町村ごとに、それぞれ登録が必要
- **建設工事**：建設業許可や経営事項審査が前提になる

資格は申請してすぐに取れるとは限らず、受付期間が決まっている自治体もあります。参加したい地域の資格は早めに確認しておきましょう。詳しくは[入札参加資格の取り方](/guide/qualification)をご覧ください。

### 2. 案件を探す

発注機関は、入札の内容や日程を「公告」として公表します。公告は発注機関のホームページや、自治体の入札情報システムなどに掲載されます。

掲載場所がばらばらなので、[じもと入札](/)のようなサイトで地域や業種から探すと効率的です。気になる案件が見つかったら、必ず発注機関の公告の原本を確認してください。

### 3. 公告・入札説明書・仕様書を読む

公告には、件名、参加資格、日程、入札の方法などが書かれています。仕様書には、具体的に何をどれだけ納めるか、どんな作業をするかが書かれています。不明な点があれば、決められた期間内に発注機関へ質問できます。

公告の読み方は[入札公告の読み方と用語集](/guide/reading-notices)で解説しています。

### 4. 参加を申し込む

一般競争入札では、入札の前に参加申請書を出し、参加資格があるかの確認を受ける形が多くあります。期限を過ぎると参加できないので注意しましょう。

### 5. 入札する

金額を書いた入札書を、決められた日時までに提出します。提出方法は、紙で持参・郵送する方法と、電子入札システムで送る方法があります。電子入札には、電子証明書（ICカード）などの準備が必要です。

多くの入札では、消費税を含まない金額（見積もった金額の110分の100）を記入するルールになっています。

### 6. 開札・落札

決められた日時に入札書が開封され、原則として、予定価格の範囲内で最も安い金額を出した事業者が落札者になります。価格だけでなく技術や提案内容も評価する方式もあります。方式の違いは[入札方式の違い](/guide/bidding-methods)をご覧ください。

### 7. 契約・履行・支払い

落札したら契約を結び、仕様書どおりに納品や作業を行います。検査に合格すると代金が支払われます。案件によっては、契約金額の一定割合を契約保証金として納める必要があります（免除される場合もあります）。

## 最初の一歩におすすめのこと

- 自社の地元の自治体で、参加資格の受付時期を確認する
- 少額の案件や、見積もりで決まる案件（オープンカウンター方式など）から経験を積む
- 過去の入札結果を見て、どれくらいの金額で落札されているかを知る

入札は、手順を一度覚えてしまえば、同じ流れで何度でも参加できます。まずは自社に合う案件がどれくらいあるか、地域や業種から探してみてください。
