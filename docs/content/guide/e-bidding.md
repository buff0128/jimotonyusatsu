# 電子入札の始め方

国や自治体の入札は、紙の入札書を持参・郵送する方式から、インターネット上のシステムで入札書を出す「電子入札」へと移ってきています。案件によっては電子入札しか受け付けていないこともあり、準備をしていないと、参加資格を持っていても入札できません。

このページでは、電子入札を始めるまでに必要な準備と、当日の流れを説明します。システムの仕様や手順は発注機関ごとに異なるため、実際に準備するときは各システムの最新の案内をご確認ください。

## 電子入札のメリット

- **移動が不要**：発注機関の窓口まで入札書を持っていく必要がありません。遠方の案件にも参加しやすくなります
- **受付期間内ならいつでも出せる**：入札書の提出期間が数日設けられていることが多く、都合のよい時間に提出できます
- **結果を早く確認できる**：開札の結果がシステム上で通知されます
- **書類の不備が減る**：入力の形式が決まっているので、記入漏れなどのミスが起きにくくなります

## どのシステムを使うかは発注機関で決まる

電子入札のシステムは、全国で1つではありません。参加したい発注機関がどのシステムを使っているかを、まず確認します。

| 発注機関・案件 | 主なシステム |
|---|---|
| 国の物品・役務（清掃、印刷、システム開発など） | 調達ポータル（政府電子調達システム） |
| 国の公共工事・建設コンサルタント業務 | 各省庁の電子入札システム |
| 都道府県・市町村 | 自治体ごとのシステムや、複数の自治体の共同システム |

公共工事向けのシステムは、国や多くの自治体が共通の仕組み（電子入札コアシステム）をもとに作っているため、対応するICカードを1枚持っていれば、複数の発注機関で使えることが多くあります。一方で、物品・役務は工事と別のシステムを使っている自治体もあるので、業種ごとに確認が必要です。

自治体のシステムは、ホームページで「電子入札」「電子調達」といった言葉で探すと案内が見つかります。

## 準備するもの

### 1. 入札参加資格

電子入札は、入札書を出す「方法」です。前提として、その発注機関の入札参加資格を持っている必要があります。資格の取り方は[入札参加資格の取り方](/guide/qualification)をご覧ください。

### 2. 電子証明書（ICカード）とICカードリーダー

電子入札では、本人であることを電子証明書で確認します。多くのシステムでは、民間の認証局が発行するICカード型の電子証明書と、パソコンにつなぐICカードリーダーを使います。

- **申し込み先**：電子入札に対応した民間の認証局（システムの案内に、対応する認証局の一覧が載っています）
- **費用**：有効期間や認証局によって異なり、数万円程度かかるのが一般的です。カードリーダーとセットで販売されていることもあります
- **発行までの期間**：書類の提出から発行まで、数週間かかることがあります
- **有効期間**：期間が決まっていて、切れる前に更新が必要です

ICカードの名義は、代表者本人にするのが基本です。支店長などに入札の権限を任せている場合（年間委任）は、その受任者の名義で取得します。いずれも、**入札参加資格で登録した内容と、ICカードの名義が一致していること**が大切です。

利用できる証明書の種類はシステムごとに異なります。ICカード以外の方式に対応しているシステムもあるので、使うシステムの案内で確認してください。

### 3. パソコンとインターネット環境

電子入札システムには、動作を確認しているOSやブラウザが決まっています。ICカードを読み取るための専用ソフトのインストールや、ブラウザの設定が必要になることもあります。

社内で複数のパソコンを使っている場合は、電子入札に使うパソコンを1台決めて、そのパソコンで設定を済ませておくと、当日のトラブルを減らせます。

## 利用開始までの流れ

1. **使うシステムを確認する**：参加したい発注機関のシステムと、対応するICカードを確認します
2. **ICカードを申し込む**：認証局に申し込み、カードとカードリーダーを受け取ります
3. **パソコンを設定する**：ICカードのソフトをインストールし、システムの案内に沿ってブラウザなどを設定します
4. **利用者登録をする**：システムにICカードを登録し、連絡先のメールアドレスなどを入力します。発注機関ごとに登録が必要な場合があります
5. **練習する**：操作を試せる体験版や練習用の画面を用意しているシステムもあります。本番の前に一度試しておくと安心です

ICカードの発行には時間がかかるため、参加したい案件が見つかってから準備を始めると間に合わないことがあります。資格の申請と並行して進めておくのがおすすめです。

## 当日までの流れ

電子入札の一般的な流れは次のとおりです。細かい手順は発注機関ごとに異なります。

1. **参加申請・資格確認の書類を出す**：一般競争入札では、入札の前に参加申請書をシステムで提出する形が多くあります
2. **参加資格の確認結果を受け取る**：参加できるかどうかの通知がシステムに届きます
3. **入札書を提出する**：決められた受付期間内に、金額を入力して送信します。工事などでは、工事費の内訳書を添付するよう求められることがあります
4. **開札・結果の確認**：開札日に結果が公表され、システムで確認できます

提出した入札書は、原則として後から書き直せません。送信の前に、金額の桁と、消費税を含まない金額になっているかを必ず確認してください（多くの入札では、税抜きの金額を記入するルールです）。

## つまずきやすいポイント

- **ICカードの有効期限切れ**：期限が切れていると、入札当日にログインできません。更新の時期をカレンダーに入れておきましょう
- **受付期間の締め切り直前の操作**：アクセスが集中したり、パソコンの設定の問題で送れなかったりすることがあります。時間に余裕をもって提出してください
- **通知メールの見落とし**：参加資格の確認結果や、日程の変更はシステムから通知されます。受信するメールアドレスは、普段確認しているものにしておきましょう
- **パソコンの更新後に動かなくなる**：OSやブラウザを更新したあとに、ICカードが読み取れなくなることがあります。入札の前には、事前に動作を確認しておくと安心です
- **紙での参加の可否**：電子入札が原則の案件でも、事前に申請すれば紙で参加できる場合があります。ただし、認められる条件は発注機関ごとに異なります

## まとめ

電子入札は、最初の準備（資格、ICカード、パソコンの設定、利用者登録）さえ済ませてしまえば、あとは毎回同じ手順で参加できます。準備には数週間かかることがあるので、早めに始めておきましょう。

準備ができたら、[じもと入札](/)で地域や業種から案件を探してみてください。公告の読み方は[入札公告の読み方と用語集](/guide/reading-notices)で解説しています。
