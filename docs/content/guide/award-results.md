# 落札結果と落札率の見方

入札に参加するとき、いちばん悩むのが「いくらで入札するか」です。高すぎれば落札できず、安すぎれば失格になったり、受注しても利益が出なかったりします。

そこで役に立つのが、過去の入札結果です。国や自治体は、入札の結果を公表しています。同じような仕事が毎年発注されることが多いため、過去の結果を見れば、金額の目安や競争の激しさをつかめます。

## 入札結果に載っている主な項目

入札結果の公表のしかたは発注機関によって違いますが、主に次のような項目が載っています。

| 項目 | 内容 |
|---|---|
| 落札者 | 契約の相手に決まった事業者 |
| 落札金額 | 落札者の入札金額（税抜きで載せている場合と、税込みの契約金額を載せている場合があります） |
| 予定価格 | 発注機関が見込んでいた上限の金額。事後に公表されることが多いです |
| 入札参加者と各社の入札金額 | 参加した事業者の名前と、それぞれの入札金額 |
| 最低制限価格 | 下回ると失格になる金額（設けている場合） |
| 落札率 | 落札金額が予定価格の何％だったか |

## 落札率とは

落札率は、次の式で計算します。

**落札率（％）＝ 落札金額 ÷ 予定価格 × 100**

たとえば、予定価格が1,000万円の工事を900万円で落札した場合、落札率は90％です。

落札率から読み取れることの例です。

- **落札率が高い（95％以上など）**：参加者が少なかった、または価格の競争があまり起きなかった可能性があります
- **落札率が低い**：参加者が多く、価格の競争が激しかった可能性があります
- **最低制限価格の近くに入札が集中している**：工事の入札などでは、多くの事業者が最低制限価格を見込んで入札し、同じ金額で並ぶことがあります。この場合、くじで落札者が決まることもあります

ただし、落札率だけで良し悪しは判断できません。予定価格の決め方や、その年の資材・人件費の状況によっても変わります。

## 過去の結果の調べ方

### 発注機関のホームページ

多くの自治体は、ホームページに「入札結果」や「契約結果」のページを設けています。電子入札のシステムで、過去の結果を検索できる場合もあります。

### 国の案件：調達ポータル

国の機関の物品・役務の入札結果は、調達ポータルで調べられます。落札者や落札金額などをまとめたオープンデータも公開されています。

### 同じ案件の前年度の結果を探す

庁舎の清掃、施設の警備、広報誌の印刷、システムの保守などは、毎年ほぼ同じ内容で発注されます。件名に年度が入っていることが多いので、年度の部分を変えて探すと、前年度の同じ案件の結果が見つかります。

### じもと入札で調べる

[じもと入札](/)では、国の案件について、調達ポータルの落札実績と案件の番号が一致したものを、案件ページの「落札結果」に載せています（落札者、落札金額、落札日）。

また、発注機関ごとのページ（案件ページや[地域のページ](/prefectures)からたどれます）では、過去12か月の月ごとの公告件数を見られます。その機関がどの時期に多く発注しているかがわかるので、毎年の発注の時期を見越して準備できます。

## 過去の結果をどう活かすか

### 1. 金額の目安をつかむ

前年度の落札金額と予定価格がわかれば、今年の入札金額を考える出発点になります。ただし、仕様（回数、面積、部数など）が前年と変わっていないか、必ず今年の仕様書と見比べてください。人件費や資材の値上がりも考えに入れます。

### 2. 競争の激しさを知る

参加者の数と、各社の入札金額の開きを見ると、その案件がどれくらい競争になっているかがわかります。

- 参加者が毎回1〜2社の案件は、新しく参加すれば選ばれる可能性があります
- 毎回同じ事業者が落札している案件は、その事業者に強みがある可能性があります。自社が勝てる理由（近さ、設備、価格）があるかを考えてみましょう

### 3. 参加しやすい案件を見つける

入札結果には「不調（参加者がいなかった）」や「不落（予定価格以下の入札がなかった）」の案件も載っています。こうした案件は、条件を見直して再び公告されることがあります。参加者が集まりにくい分野や地域は、新しく参入する事業者にとってチャンスです。

### 4. 発注の時期を知る

同じ発注機関の結果を並べると、どの時期にどんな案件が出るかが見えてきます。年度の初めや、予算が決まった直後に発注が集中する分野もあります。

## 気をつけること

- **税抜きか税込みか**：公表されている落札金額が、税抜きの入札金額なのか、税込みの契約金額なのかを確認してから比べましょう
- **予定価格が公表されていない場合**：落札率は計算できません。前年度の落札金額と仕様を比べて目安にします
- **最低制限価格を下回らないように**：相場より安く入れようとして、最低制限価格を下回ると失格になります。最低制限価格は事前に公表されないことが多いので、過去の結果から予定価格との割合の目安をつかんでおくと参考になります
- **金額だけで決めない**：自社の費用を積み上げた金額を基本にし、過去の結果はあくまで参考にします。赤字になる金額での受注は避けましょう

## まとめ

過去の入札結果は、入札金額の目安、競争の激しさ、発注の時期を教えてくれる、いちばん身近な情報源です。参加したい案件が見つかったら、まず前年度の同じ案件の結果を探してみてください。

金額に関する用語は[入札公告の読み方と用語集](/guide/reading-notices)で、失格にならないための注意点は[失格・無効にならないためのチェックリスト](/guide/checklist)で解説しています。
