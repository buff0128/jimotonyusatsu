# 入札参加資格の取り方

官公庁の入札に参加するには、多くの場合、事前に「入札参加資格」を取得しておく必要があります。資格は発注する機関によって分かれていて、1つ取ればどこでも参加できるわけではありません。

このページでは、資格の種類と申請の流れを説明します。なお、申請方法や受付期間は機関ごとに異なり、変更されることもあります。実際に申請する際は、必ず各機関の最新の案内をご確認ください。

## 資格の種類

### 国の機関：全省庁統一資格

国の省庁などが発注する**物品の製造・販売、役務の提供（清掃、警備、印刷、システム開発など）**の入札に参加するための資格です。1回の申請で、各省庁の入札に共通して使えます。独立行政法人などでも、この資格を参加条件にしている場合があります。

- **申請先**：国の「調達ポータル」から申請します
- **区分**：「物品の製造」「物品の販売」「役務の提供等」「物品の買受け」に分かれています
- **等級**：売上高や自己資本などをもとにA〜Dの等級が付き、等級によって参加できる案件の規模が決まります
- **有効期間**：一定の期間（数年単位）ごとに更新が必要です
- **費用**：申請手数料はかかりません

### 自治体：都道府県・市町村ごとの資格

自治体の入札に参加するには、その自治体ごとに資格の登録が必要です。たとえば茨城県の物品・役務の入札なら、茨城県の物品調達等の競争入札参加資格が必要になります。

- 受付期間が決まっていて、その時期を逃すと次の受付まで待つ自治体もあります
- 随時受け付けている自治体もあります
- 自治体によっては、本店や営業所がその地域にあることを条件にしている場合があります
- いくつかの市町村が共同で受け付けている地域もあります

参加したい自治体のホームページで、「入札参加資格」「競争入札参加資格」といった言葉で探すと案内が見つかります。

### 建設工事・建設コンサルタント業務

工事の入札は、物品・役務よりもハードルが高くなります。

- 建設業許可を持っていること
- 経営事項審査（経審）を受けていること
- そのうえで、発注者ごとの工事の競争参加資格を取ること

測量・設計などの建設コンサルタント業務にも、別の資格区分があります。

## 申請の一般的な流れ

1. **参加したい発注機関を決める**：自社の所在地の自治体と、案件の多い国の出先機関から始めるのが一般的です
2. **受付期間と必要書類を確認する**：登記事項証明書、納税証明書、財務諸表などが求められることが多いです
3. **申請する**：オンライン申請、郵送、持参など、機関ごとに方法が異なります
4. **審査・登録**：審査が終わると資格者名簿に登録され、入札に参加できるようになります
5. **電子入札の準備**：電子入札で参加する場合は、電子証明書（ICカード）の取得や、パソコンの設定が別途必要です

## 自分で申請するか、専門家に頼むか

書類をそろえれば自分で申請できますが、複数の自治体に申請する場合は手間がかかります。行政書士などの専門家に申請の代行を依頼する方法もあります。

## よくある質問

**個人事業主でも資格は取れますか？**
多くの場合、取得できます。必要書類が法人と異なることがあるので、各機関の案内を確認してください。

**資格を取ればすぐに入札できますか？**
資格は参加の前提条件です。案件ごとに、等級や地域、実績などの追加条件が付いていることがあるので、公告で確認する必要があります。

資格の準備ができたら、[入札の始め方](/guide/getting-started)の流れに沿って、案件を探してみてください。
