# 入札公告の読み方と用語集

入札公告は、発注機関が「この内容で入札を行います」と知らせる文書です。独特の言葉が多いですが、確認するポイントは決まっています。

## 公告で必ず確認する5つのポイント

1. **何を発注するか**：件名と、業務・納品の内容。詳しくは仕様書に書かれています
2. **参加資格**：必要な入札参加資格の種類と等級、地域の条件、過去の実績の条件など
3. **日程**：参加申請の期限、質問の期限、入札書の提出期限、開札日
4. **入札の方法**：紙か電子か、価格だけで決めるのか、提案も評価するのか
5. **お金の条件**：予定価格の公表の有無、入札保証金・契約保証金の要否

## 日程に関する用語

| 用語 | 意味 |
|---|---|
| 公告日 | 入札の内容が公表された日 |
| 参加申請の期限 | 参加申請書や資格確認の書類を出す締め切り。これを過ぎると参加できません |
| 質問の期限 | 仕様などについて発注機関に質問できる締め切り |
| 入札書の提出期限 | 金額を書いた入札書を出す締め切り。電子入札では受付期間が決まっていることが多いです |
| 開札日 | 入札書を開封して、落札者を決める日 |
| 履行期間・納入期限 | 業務を行う期間や、物品を納める期限 |

## 金額に関する用語

| 用語 | 意味 |
|---|---|
| 予定価格 | 発注機関が見込んでいる上限の金額。これを超える入札は落札できません。事前に公表される場合と、されない場合があります |
| 最低制限価格 | これを下回ると失格になる下限の金額。安すぎる金額での受注による品質低下を防ぐために設けられます |
| 低入札価格調査基準価格 | これを下回った場合に、その金額で適切に履行できるかを調査する基準の金額 |
| 入札保証金 | 入札に参加する際に納める保証金。免除されることも多いです |
| 契約保証金 | 契約を結ぶ際に納める保証金。契約金額の一定割合が一般的で、免除される場合もあります |
| 単価契約 | 「1部あたり〇円」のように単価で契約し、実際の数量に応じて支払う方式 |

## 入札・落札に関する用語

| 用語 | 意味 |
|---|---|
| 一般競争入札 | 条件を満たせば誰でも参加できる入札 |
| 指名競争入札 | 発注機関が指名した事業者だけが参加できる入札 |
| 電子入札 | インターネット上のシステムで入札書を提出する方法 |
| 紙入札 | 入札書を紙で持参・郵送する方法 |
| 落札 | 契約の相手方に決まること |
| 不落 | 予定価格以下の入札がなく、落札者が決まらないこと。再度入札を行う場合があります |
| 不調 | 参加者がいないなどで、入札が成立しないこと |
| 入札説明書 | 入札の手続きや条件を詳しく説明した文書 |
| 仕様書 | 業務や物品の具体的な内容・数量・品質を定めた文書 |

入札の方式の違いは[入札方式の違い](/guide/bidding-methods)で詳しく説明しています。

## 読むときのコツ

- **まず参加資格と日程を見る**：資格が合わない、期限に間に合わない案件は、内容を読み込む前に外せます
- **仕様書の数量と期間を確認する**：自社で対応できる規模かどうかを判断します
- **変更・訂正の公告に注意する**：公告後に日程や内容が変わることがあります。発注機関のページを最後まで確認しましょう

じもと入札の案件ページでは、公告の主な項目を整理して掲載しています。ただし、正式な内容は必ず発注機関の公告の原本でご確認ください。
