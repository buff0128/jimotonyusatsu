# じもと入札 デザインガイド

見本（正解）は `docs/design/*.dc.html` です。色・余白・角丸・フォントサイズはすべて見本のHTMLに書き込まれています。迷ったら見本の値をそのまま使ってください。このファイルは、見本に共通するルールをまとめたものです。

| 見本 | 対応するページ |
|---|---|
| `LocalHome.dc.html` | トップ（地元が未選択のとき） |
| `LocalCity.dc.html` | 市区町村ページ（例：`/ibaraki/mito`）。都道府県ページも同じ構成 |
| `LocalDetail.dc.html` | 案件詳細 `/cases/{id}` |
| `AfterList.dc.html` | 一覧・検索・業種ページの**構成**（絞り込み、案件カード、並び順、ページ送り）。**色は古いので、このファイルの色ルールに置き換える** |

※ `.dc.html` はデザインツール用の形式です。`<x-dc>` の中身が画面のHTML、`<helmet>` の中がフォントとページ共通のスタイルです。`./support.js` やスクリプトは無視してください。

## コンセプト

**「町の掲示板」**。全国のデータベースを絞り込むのではなく、「自分の町の仕事が貼り出されている場所」として見せる。

- 地名を主役にする（案件カードの先頭は地名、見出しは「水戸市で今受けられる仕事」）
- 暖かい3色（生成り・墨・柿）でまとめる
- 藍はロゴの文字だけに使う。サイトの文字・面には使わない（リンクも柿渋の茶色。2026-11-08 に変更）

**種別の色**（小さな丸いタグ）
- 役務：背景 `#F1EAFD`／文字 `#6A3FC0`
- 物品：背景 `#E8F3EB`／文字 `#2F6B3E`
- 工事：背景 `#FBEFE3`／文字 `#8A4B0F`

**使わないもの**：グラデーション、藍の面（濃い藍の帯や、青みがかったラベル）、絵文字、左側だけ太線のカード。

**リンク**：本文中のリンクは下線を付ける（色だけに頼らない）。下線は `text-underline-offset: 0.2em`・太さ1px。カード・ピル・ナビなど、形でリンクと分かるものは下線なし。

## 文字

- 本文：Noto Sans JP（400/500/700/900）、15px、行間1.7
- 見出し（h1〜h3）と大きい数字：M PLUS Rounded 1c（700/800）、色は `--ink-heading`
- サイズの目安
  - トップの大見出し 44px／ページの見出し 38px／案件詳細の件名 28px
  - セクション見出し 22〜24px／サイドの見出し 15〜17px
  - 案件カードの件名 17px（太字）／補足 13px／注記 12px

## 形・余白

- 角丸：大きいカード 16px、案件カード 14px、ボタン・入力欄 10px、参加しやすさのラベル 6px、タグ・ピル 999px
- 影はほぼ使わない：カード `0 1px 2px rgba(60,40,20,0.05)` 程度
- コンテンツ幅 1200px、左右の余白 24px
- 要素の間隔：同じ組の中 6〜8px ＜ 組と組の間 12〜16px ＜ ブロックの間 20〜24px ＜ セクションの間 40px
- タップできる要素は高さ44px以上

## 部品のルール

**ヘッダー**：ロゴ（`logo-horizontal.svg`、高さ34〜36px）、地元ピル「地元：茨城県 水戸市（変更）」、検索窓（丸いピル型）、お気に入り（☆と件数バッジ）。地元が未選択なら地元ピルは出さない。

**案件カード**
- 1行目：地名（`--kaki-text`・太字）｜種別・業種（`--muted`）
- 2行目：件名（17px・太字）
- 3行目：発注機関（13px・`--muted`）
- 4行目：参加しやすさのラベル（`--label-bg`）
- 右側：締切の箱と☆ボタン（44px）

**締切の箱**
- 7日以内：`--kaki-soft` の面に `--kaki-text` の文字
- 8日以上：`--surface-soft` の面に枠線
- 締切が取れていない：「締切 公告で確認」
- 受付終了：カード全体を薄くし、一覧の下にまとめる
- 「あと◯日」はブラウザ側で計算する（キャッシュの影響を受けないように）

**掲示板の貼り紙**（トップの掲示板、都道府県・市区町村ページの「今週のねらい目」だけ。一覧・検索・詳細のカードは傾けない）
- 面は `.board-face`（`--board`・角丸 `--radius-board`）、貼り紙は `.board-note`（白・角丸10px・影 `--shadow-note`）
- 貼り紙は並び順で -1.2〜1.2度傾ける（`.board-notes` の子の順に -1.2 / 0.8 / -0.5 / 1.1 / -0.9 / 0.5度）。390px 以下では半分
- 上の中央に、柿のピン（`.board-pin`、14px の丸・`--kaki`）とマスキングテープ（`.board-tape`、64×18px・`--tape`・-3度）を交互に付ける
- ホバーで3px浮かせ、傾きを0に戻す（動きを減らす設定では動かさない）

**業種のアイコン**：`src/components/GyoshuIcon.astro`。業種（`src/lib/gyoshu.ts`）ごとに1つ、このサイト用に描いた単色の線画。24pxの枠・線の太さ1.75・角は丸・`currentColor`。案件カードでは15px・`--muted`（種別・業種の文字の前）、「業種から探す」では16〜20px・`--kaki-text`。業種を足したらアイコンも描き足す（見本：`docs/design/gyoshu-icons-2026-11-08.png`）

**新着のピル**：公告日から3日以内（日本時間、公告日を0日目として3日目まで）。`--kaki-soft` の面に `--kaki-text` の文字（4.7:1）、角丸 `--radius-pill`、12px・太字。出すかどうかはブラウザで決める（`src/scripts/countdown.ts`）。案件カードは1行目の業種の後ろ、詳細は上の枠の種別タグの並び

**小さな動き**：☆を押して登録したときに☆が上から刺さる動き（0.32秒）、貼り紙のホバー、件数のタイルの数え上げ（0.7秒）。どれも `prefers-reduced-motion: reduce` では出さない。動きは短く、1回だけ

**カレンダー・共有・印刷**（案件詳細）：「カレンダーに追加」は `<details>` で下に開くメニュー（Googleカレンダー／.ics）。重ねて出さない（右端の列ではみ出さないため）。「リンクをコピー」「LINEで送る」「印刷」は右の枠のお気に入りの下に、高さ44pxのボタンで並べる。印刷では `.no-print` の部品（ヘッダー・フッター・横の枠・ボタン類）を消し、件名・機関・日程・要約・参加のポイント・公告URLを A4 1枚に収める

**AIの表示**：要約には「AIによる要約」の小さなバッジ。AIが読み取った項目には紫の「AI」の印（`#6A3FC0`）と、その意味の注記。

## 地元の選択

- トップで都道府県・市区町村を選ぶと、ブラウザ（localStorage）に保存する
- 保存済みの人がトップを開いたら、その市区町村のページへ移動する。ただし、ヘッダーのロゴからトップに戻ったとき（`?home=1` など）は移動しない
- ヘッダーの地元ピルの「変更」でトップに戻り、選び直せる
- 検索エンジン向けのHTMLは、地元の選択に関係なく同じ内容にする（保存の有無で変わるのはブラウザ側の動きだけ）

## 文言

- 「案件」より「仕事」：「水戸市で今受けられる仕事」「今週新しく出た仕事」「締切が近い仕事」
- 地名を主語にする：「水戸市の入札」「水戸市でよく発注する機関」「となりの市町村」
- 掲示板の言い回しで、話し言葉寄りに：「新しく貼り出された仕事」「まだ貼り出されていません」「条件を少しゆるめてみてください」
- ただし事実と違うことは書かない（「毎日更新」「毎朝」など。docs/LOG_2026-11-05.md の「あとで戻すもの」にある表現は、条件がそろうまで使わない）
